### What I'm building

**[enavu-hub](https://github.com/enavu/agenticai)** · [enavu.io](https://enavu.io)

Self-hosted AI personal automation hub — built entirely with Claude Code. An experiment in AI-native development: 4 weeks of architecture planning, ~9 hours of active coding, running live on a rescued $100 MacBook Pro.

- **Smart home agent** — Claude ReAct loop controls 505 Home Assistant devices via natural language. Ask it what lights are on, turn off everything, check the thermostat.
- **Fitness tracker** — Playwright scraper pulls 738 Cyclebar rides (212k+ calories) from the members portal. Daily automated sync.
- **Content agent** — Generates Instagram captions from workout data and auto-posts on a schedule. Full reasoning trace visible in the UI.
- **Finance tracker** — Private lease accountability tracker. Payment status auto-computed from dates and amounts. Reliability score weighted across payment history.

Stack: `Go` `Python` `TypeScript` `Next.js` `PostgreSQL` `Redis` `Claude API` `Playwright` `Docker` `Caddy` `Cloudflare`
